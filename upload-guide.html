📋 File Requirements

Accepted Format

CSV files only — Maximum file size: 4 MB

Important
  • Only CSV format accepted — Excel files (.xlsx, .xls) must be converted to CSV first
  • File size limit: 4 MB — Larger files will be rejected
  • Files exceeding limits? See troubleshooting below

Why CSV?

CSV (Comma-Separated Values) is a universal, lightweight format that:

  • ✅ Works across all platforms and software
  • ✅ Loads faster than Excel files
  • ✅ Reduces processing errors
  • ✅ Ensures data privacy (no hidden metadata)

🔄 How to Convert Excel to CSV

Method 1: Using Microsoft Excel (Windows/Mac)

1 Open your Excel file containing the clinical data
2 Click "File" → "Save As"
3 Choose save location (Desktop or Documents folder recommended)
4 In "Save as type" dropdown, select:
  • CSV (Comma delimited) (*.csv) — Recommended
  • CSV UTF-8 (Comma delimited) (*.csv) — For international characters
5 Click "Save"
Excel Warning Message

Excel may show: "Some features in your workbook might be lost if you save it as CSV"

This is normal! Click "Yes" to continue. CSV files only save data (no formatting, formulas, or multiple sheets).

Method 2: Using Google Sheets

1 Upload your Excel file to Google Drive or open it in Google Sheets
2 In Google Sheets, click File → Download → Comma Separated Values (.csv)
3 The CSV file downloads to your Downloads folder automatically

Method 3: Using LibreOffice Calc (Free)

1 Open file in LibreOffice Calc (free alternative to Excel)
2 Go to "File" → "Save As"
3 Select format: Text CSV (.csv)
4 Click "Save" and confirm settings

✅ Data Preparation Best Practices

Before Converting to CSV:

✅ Do This ❌ Avoid This
Use a single sheet with data Multiple sheets (only first sheet converts)
Have column headers in Row 1 Missing or unclear column names
Keep data clean and consistent Merged cells, blank rows, or complex formatting
Use standard date format (YYYY-MM-DD) Mixed date formats
Remove PHI before uploading Patient names, MRNs, SSN, addresses
Use numeric values for numbers Dollar signs, commas (e.g., use 1000 not $1,000)

Remove Protected Health Information (PHI):

HIPAA Compliance Required

Before uploading, remove all 18 HIPAA identifiers:

  • Names, addresses, phone numbers, email addresses
  • Social Security Numbers, Medical Record Numbers
  • Dates of birth, dates of service (except year)
  • Photos, biometric data, IP addresses
  • Any other unique identifying information

For SUD data: 42 CFR Part 2 restrictions apply — ensure proper de-identification and authorization.

🔧 Troubleshooting

Problem: File is Larger Than 4 MB

Solutions:

  • Filter data: Remove unnecessary rows (e.g., old records, test data)
  • Remove columns: Keep only essential clinical fields for analysis
  • Split data: Analyze data in smaller batches (e.g., by quarter, by facility)
  • Aggregate data: Summarize detailed records into aggregated metrics
  • Compress: Some large text fields can be shortened or categorized

Problem: File Not Uploading

Check:

  • ✓ File is .csv format (not .xlsx, .xls, .txt)
  • ✓ File size is under 4 MB
  • ✓ File name doesn't have special characters (! @ # $ % & * ( ))
  • ✓ CSV file is properly formatted (commas as delimiters, headers in row 1)

Problem: Charts Are Empty or Incorrect

Check your data:

  • ✓ Column headers clearly describe the data (e.g., "Patient Count" not "Column1")
  • ✓ Numeric columns contain only numbers (no text like "N/A" or "Unknown")
  • ✓ Date columns use consistent format
  • ✓ Dataset has enough rows (minimum 10-20 records recommended)

Problem: Error Message About File Format

If you see: "Invalid file type. Only CSV files accepted."

  • Your file must be a true CSV, not an Excel file renamed to .csv
  • Re-save using File → Save As → CSV (Comma delimited) in Excel
  • Or use Google Sheets: File → Download → CSV

📊 Example Data Structure

Good CSV Structure Example:

Example: Substance Use Disorder Follow-Up Data

Patient_ID,Age,Gender,Substance_Type,Treatment_Date,Follow_Up_7_Days,Follow_Up_30_Days
001,34,M,Opioid,2024-01-15,Yes,Yes
002,28,F,Alcohol,2024-01-18,Yes,No
003,45,M,Opioid,2024-01-20,No,No
004,31,F,Stimulant,2024-01-22,Yes,Yes

✓ This structure works because:

  • Clear, descriptive column headers
  • Consistent data types in each column
  • No PHI (using Patient_ID instead of names)
  • Clean Yes/No values (not "Y", "yes", "YES")
  • Standard date format (YYYY-MM-DD)
